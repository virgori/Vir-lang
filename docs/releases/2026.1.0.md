# Vir 2026.1.0

Vir 2026.1.0 is the first official calendar-versioned compiler release. The
GitHub distribution/tag version is `v2026.1.0`; the compiler identifies itself
as `2026.1` without a leading `v` or official `.0` suffix.

The requested comparison baseline is Vir 3.8.2. The public GitHub repository
did not contain a `v3.8.2` tag when this release was prepared, so the resolved
work below is derived from the repository's VPS ISSUE and accepted REPORT
evidence rather than a Git tag diff.

## Highlights

- Calendar versioning with a canonical machine-readable compiler version,
  idempotent per-ISSUE bump tooling, and release-policy regression tests.
- Fully modular self-hosted compiler source tree with synchronized generated
  bundle and byte-identical Stage 2/Stage 3 bootstrap.
- Hardened project/stdlib module identity, native project ingestion, toolchain
  sysroot discovery, and CWD-independent standard-library resolution.
- Production MIR optimization, tail calls, typed tensor/quantization metadata,
  target separation, native float printing, and expanded backend verification.
- Strict classic/modern CLI contracts, structured diagnostics, IDE semantic
  facts, and native LSP integration.
- `vir-lsp` reset to independent Semantic Version `1.3.0` with its own bump
  policy, canonical metadata, and protocol-version regression checks.

- `VIR-ISS-0009` records the calendar-versioning migration and release mapping.
- `VLSP-ISS-0001` records the independent `vir-lsp` Semantic Version policy.
- `virc --version`: `virc 2026.1 (self-hosted)`.
- `vir-lsp --version`: `vir-lsp 1.3.0`.

## Verification

- Compiler Stage 2 and Stage 3 bootstrap binaries are byte-identical.
- Compiler CLI contracts: 43/43 pass.
- Toolchain sysroot contracts: 42/42 pass.
- Compiler and LSP version-policy checks pass.
- Native LSP initialize/shutdown/exit protocol test passes.
- Linux ARM64 and Linux x86_64 executables pass real ELF execution tests:
  each compiler builds and runs a target-native smoke program, and each LSP
  completes the initialize/shutdown/exit protocol lifecycle.
- Generated compiler source and VPS registry validation pass.

## Release assets

The release publishes statically linked `virc` and `vir-lsp` executables for:

- macOS ARM64;
- Linux ARM64;
- Linux x86_64.

`SHA256SUMS.txt` covers every published executable. Other targets remain
source-build targets unless a separate verified asset is attached. The
`vir-stdlib-2026.1.0.tar.gz` asset supplies the versioned sysroot used by the
cross-platform installer.
