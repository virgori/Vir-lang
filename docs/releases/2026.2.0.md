# Vir 2026.2.0

Vir 2026.2 is the second official calendar-versioned compiler release of
2026. The GitHub tag is `v2026.2.0`; the compiler identifies itself as
`2026.2` without a leading `v` or official `.0` suffix.

This ledger is derived from VPS ISSUE state at the release snapshot and lists
work that reached `CLOSED` after Vir 2026.1. Non-terminal work is deliberately
excluded. In particular, `VIRC-ISS-0049` is `REOPENED` and is not claimed as
resolved by this release.

## Highlights

- Canonical include/import/export boundaries, private-by-default selective
  imports, namespace-aware whole-module imports, multi-include support, and
  collision-safe registry diagnostics.
- Focused entity-method and UFCS contracts, including callable shadowing,
  generic receivers, and field/method name coexistence.
- Self-hosted native verification replacing Python test orchestration, strict
  VPS token consumption, and independently versioned native LSP tooling.
- Correct typed memory widths, packed `f32` tensor fixtures, static autodiff,
  quantization storage, `INT64_MIN` formatting, register isolation, and
  controlled call-stack exhaustion diagnostics.
- Native and cross-target `@bind` ABI verification across mixed register,
  stack, pointer, scalar, and fail-closed unsupported cases.
