# VIR Paper Standard Changelog

This changelog records only VPS standard, schema, template, skill, and tooling
changes. It is not a compiler or product changelog.

## 1.1.0 — 2026-10-02

- Added SPEC papers with the stable `SPC` namespace.
- Added semantic SPEC versions, specification classes, language tags, aliases,
  lifecycle states, schema, template, CLI creation, and validation.
- Established `papers/<DOMAIN>/specs/` as the canonical specification location.
- Added the `IVIR` and `VIRON` domains for InterVir and Viron specifications.

## 1.0.0 — 2026-10-02

- Established VIR Paper Standard v1.
- Added ISSUE, PLAN, and REPORT document classes.
- Added VIR, VIRC, VLSP, and STLB namespaces.
- Added production and example registries.
- Added JSON Schemas, Markdown templates, deterministic validation tooling,
  and the `vir-paper-management` project skill.
